# Linux packages

Native packages for Debian, Ubuntu, RHEL, Fedora, CentOS, and Alpine Linux are available from the [Augias repository on Cloudsmith](https://cloudsmith.io/~solidworx/repos/augias/packages/). Installing a package sets up a systemd service, places the binary at `/usr/bin/augias`, and creates a dedicated service user — nothing else to configure to get started.

## Install

<Tabs groupId="pkg-manager">
  <TabItem value="apt" label="Debian / Ubuntu" default>

  Add the Augias APT repository and install:

  ```bash
  curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.deb.sh' | sudo -E bash
  sudo apt install augias
  ```

  </TabItem>
  <TabItem value="dnf" label="RHEL / Fedora / CentOS">

  Add the Augias RPM repository and install:

  ```bash
  curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.rpm.sh' | sudo -E bash
  sudo dnf install augias
  ```

  :::note
  On CentOS 7 or RHEL 7, substitute `yum` for `dnf`.
  :::

  </TabItem>
  <TabItem value="apk" label="Alpine">

  Add the Augias Alpine repository and install:

  ```bash
  curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.alpine.sh' | sudo -E sh
  sudo apk add augias
  ```

  </TabItem>
</Tabs>

:::info
Packages are GPG-signed. The setup scripts configure the signing key automatically — no manual key import needed.
:::

## Start the service

Enable and start the systemd service:

```bash
sudo systemctl enable augias --now
```

Augias listens on `http://localhost:8765`. Open that URL in your browser and finish setup with the [first-run wizard](./system-installation.md).

:::info
The service runs over plain HTTP by default. For production, place Augias behind a reverse proxy (Nginx, Caddy, Traefik) that handles TLS termination.
:::

## Configuration

The service reads configuration from `/etc/augias/augias.env`. Edit this file to change the port, set the database URL, or override any other option:

```ini title="/etc/augias/augias.env"
# Port to listen on (default: 8765)
#AUGIAS_PORT=8765

# Database connection string
#DATABASE_URL=mysql://user:password@localhost:3306/augias
```

After editing, restart the service to apply changes:

```bash
sudo systemctl restart augias
```

## Manage the service

```bash
sudo systemctl start augias     # start
sudo systemctl stop augias      # stop
sudo systemctl restart augias   # restart
sudo systemctl status augias    # check status
journalctl -u augias -f         # follow logs
```

## File locations

| Path | Contents |
| --- | --- |
| `/usr/bin/augias` | Binary |
| `/etc/augias/augias.env` | Configuration |
| `/var/lib/augias/` | Application data |
| `/usr/lib/systemd/system/augias.service` | systemd unit |
