# Paquet de distribution

Le paquet de distribution est une archive prête à l'emploi d'Augias, servie par un serveur web PHP existant. Choisissez cette méthode quand l'[installation rapide](../quick-install.mdx) n'est pas possible : hébergement mutualisé, hébergeur PHP géré, ou politique d'entreprise qui impose un serveur web.

:::warning
C'est la méthode la plus exigeante. Le serveur web, PHP, la base de données, la tâche cron et le worker asynchrone sont à votre charge. Si vous avez le choix, l'[installation rapide](../quick-install.mdx), [Homebrew](../homebrew.md) ou [Docker](../docker.md) s'occupent de tout cela pour vous.
:::

:::tip[À qui s'adresse cette méthode]
Elle suppose que vous faites déjà tourner un serveur web PHP et que vous savez l'entretenir.
:::

## Configuration requise

- **PHP 8.4 ou plus** avec les extensions `curl`, `gd`, `intl`, `json`, `openssl`, `pdo`, `soap` et `xsl`, et un pilote `pdo` pour votre base (`pdo_mysql`, `pdo_pgsql` ou `pdo_sqlite`).
- Un serveur web : **Nginx** (conseillé) ou **Apache** avec `mod_rewrite`.
- Une base de données prise en charge (MySQL, MariaDB, PostgreSQL ou SQLite).
- La possibilité de lancer une tâche cron et un processus PHP de longue durée sur la machine.

## 1. Télécharger

Téléchargez l'archive de la dernière version sur la [page des versions](https://github.com/herc-si/Augias/releases/latest), par exemple :

```bash
VERSION=4.1.0

# Zip
curl -LO "https://github.com/herc-si/Augias/releases/download/${VERSION}/Augias-${VERSION}.zip"

# Ou tar.gz
curl -LO "https://github.com/herc-si/Augias/releases/download/${VERSION}/Augias-${VERSION}.tar.gz"
```

Décompressez-la dans un dossier servi par votre serveur web, par exemple `/opt/augias`.

:::info
Sur un hébergement mutualisé accessible seulement en FTP, téléchargez et décompressez l'archive sur votre poste, puis envoyez les fichiers décompressés sur votre hébergement.
:::

## 2. Configurer le serveur web

Faites pointer votre serveur web sur le dossier `public/` de l'archive décompressée.

<Tabs groupId="webserver">
  <TabItem value="nginx" label="Nginx" default>

  ```nginx
  server {
      server_name votredomaine.fr www.votredomaine.fr;
      root /opt/augias/public;

      location / {
          # servir le fichier s'il existe, sinon index.php
          try_files $uri /index.php$is_args$args;
      }

      location ~ ^/index\.php(/|$) {
          fastcgi_pass unix:/var/run/php-fpm.sock;
          fastcgi_split_path_info ^(.+\.php)(/.*)$;
          include fastcgi_params;
          fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
          fastcgi_param HTTPS off;
      }

      error_log /var/log/nginx/augias_error.log;
      access_log /var/log/nginx/augias_access.log;
  }
  ```

  </TabItem>
  <TabItem value="apache" label="Apache">

  ```apacheconf
  <VirtualHost *:80>
      ServerName votredomaine.fr
      ServerAlias www.votredomaine.fr

      DocumentRoot /opt/augias/public
      <Directory /opt/augias/public>
          # active les réécritures du .htaccess
          AllowOverride All
          Require all granted
      </Directory>

      ErrorLog /var/log/apache2/augias.error.log
      CustomLog /var/log/apache2/augias.access.log combined
  </VirtualHost>
  ```

:::warning
Les chemins exacts (socket PHP-FPM, dossiers de journaux) varient selon le système et la version de PHP. Adaptez-les à votre environnement.
:::

Ouvrez dans votre navigateur l'adresse servie par le serveur web et terminez avec l'[assistant de premier démarrage](../system-installation.md) : il vous guide pour la connexion à la base, le compte administrateur et les réglages de base de l'application.

## 3. Lancer le processus de fond

Augias utilise un seul processus de fond pour les messages asynchrones (e-mails, webhooks) et les tâches planifiées (factures récurrentes, relances, passage en retard). Il fait tourner `bin/console messenger:consume --all` en boucle.

Suivez le guide des [tâches planifiées](./cron-job-setup.md) : il couvre systemd, cron, cPanel, Plesk et le Planificateur de tâches de Windows.

:::warning
Sans ce processus, ni les fonctions asynchrones ni les tâches planifiées ne s'exécutent : les e-mails ne partent pas et les factures récurrentes ne sont pas générées.
:::

## Variables d'environnement utiles

L'assistant de premier démarrage règle tout ce qu'il faut pour commencer. Les variables ci-dessous servent à surcharger des réglages, à automatiser un déploiement, ou à régler ce que l'assistant ne demande pas. Placez-les dans `.env.local` (ou dans l'environnement de votre serveur web).

| Variable | Description |
| --- | --- |
| `AUGIAS_ENV` | L'environnement de l'application. `prod` en production. |
| `AUGIAS_DEBUG` | Active les pages d'erreur détaillées. `0` en production. |
| `AUGIAS_APP_SECRET` | Une longue chaîne aléatoire qui signe les cookies et les jetons CSRF. |
| `AUGIAS_APPLICATION_URL` | L'adresse publique de l'installation, par exemple `https://factures.example.com`. |
| `AUGIAS_DATABASE_URL` | Le DSN de la base de données. L'assistant peut aussi l'écrire pour vous. |
| `AUGIAS_MAILER_DSN` | Le transport d'envoi des e-mails par défaut (SMTP, Mailgun, SendGrid, etc.), utilisé par toute entreprise qui n'a pas réglé le sien dans `Paramètres` > `E-mail`. Voir [Envoyer des e-mails](../sending-emails.md). |
| `AUGIAS_MAILER_SENDER` | L'adresse `From:` des e-mails d'Augias. Remplace celle réglée dans l'application. |
| `AUGIAS_LOCALE` | La langue par défaut (par exemple `fr`). |
| `AUGIAS_DEFAULT_CURRENCY` | La devise d'une nouvelle entreprise. `EUR` par défaut. |
| `AUGIAS_CURRENCIES` | Les devises proposées aux entreprises et aux clients, séparées par des virgules (par exemple `EUR,CHF,GBP`). Vide par défaut : toutes les devises sont proposées. Les factures fournisseurs acceptent toujours toutes les devises. |
| `AUGIAS_TELEMETRY_URL` | L'adresse où envoyer des chiffres d'usage anonymes. Vide par défaut, et Augias ne fournit pas de collecteur : laissez-la vide, et rien n'est jamais envoyé nulle part. |
| `AUGIAS_ENABLE_TELEMETRY` | `1` pour envoyer ces chiffres au collecteur ci-dessus. Désactivée par défaut, et sans effet seule : les deux variables doivent être réglées. |

La télémétrie, si vous l'activez, transmet votre version, votre système, votre version de PHP, votre moteur de base de données et votre type d'installation, ainsi que des événements nommés comme « une facture a été créée ». Elle ne transporte jamais vos données, vos clients ni vos montants.

Les autres intégrations (Sentry, Meilisearch, connexion Google) ont leurs propres variables, décrites sur leurs pages.

## Mettre à jour

1. Arrêtez le processus de fond : `sudo systemctl stop augias-worker.service` (ou commentez la ligne cron).
2. Sauvegardez votre base de données et le dossier du projet.
3. Téléchargez la nouvelle archive et remplacez les fichiers du projet, en **gardant** votre `.env.local` et vos modifications.
4. Lancez `bin/console cache:clear --env=prod` puis `bin/console doctrine:migrations:migrate --env=prod --no-interaction`.
5. Redémarrez le processus de fond.
