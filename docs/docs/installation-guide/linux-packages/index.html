Paquets Linux

Des paquets natifs pour Debian, Ubuntu, RHEL, Fedora, CentOS et Alpine Linux sont disponibles dans le dépôt Augias sur Cloudsmith. Le paquet installe un service systemd, place le binaire dans /usr/bin/augias et crée un utilisateur dédié : rien d'autre à configurer pour démarrer.

Installer​

  • Debian / Ubuntu
  • RHEL / Fedora / CentOS
  • Alpine

Ajoutez le dépôt APT d'Augias et installez :

curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.deb.sh' | sudo -E bash
sudo apt install augias

Ajoutez le dépôt RPM d'Augias et installez :

curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.rpm.sh' | sudo -E bash
sudo dnf install augias
remarque

Sur CentOS 7 ou RHEL 7, remplacez dnf par yum.

Ajoutez le dépôt Alpine d'Augias et installez :

curl -1sLf 'https://dl.cloudsmith.io/public/solidworx/augias/setup.alpine.sh' | sudo -E sh
sudo apk add augias
info

Les paquets sont signés GPG. Les scripts d'installation configurent la clé de signature : aucune importation manuelle.

Démarrer le service​

Activez et démarrez le service systemd :

sudo systemctl enable augias --now

Augias écoute sur http://localhost:8765. Ouvrez cette adresse dans votre navigateur et terminez avec l'assistant de premier démarrage.

info

Le service sert en HTTP simple par défaut. En production, placez Augias derrière un proxy inverse (Nginx, Caddy, Traefik) qui gère le TLS.

Configuration​

Le service lit sa configuration dans /etc/augias/augias.env. Modifiez ce fichier pour changer le port, régler l'adresse de la base de données ou toute autre option :

/etc/augias/augias.env
# Port d'écoute (défaut : 8765)
#AUGIAS_PORT=8765

# Connexion à la base de données
#DATABASE_URL=mysql://user:password@localhost:3306/augias

Après modification, redémarrez le service :

sudo systemctl restart augias

Piloter le service​

sudo systemctl start augias     # démarrer
sudo systemctl stop augias      # arrêter
sudo systemctl restart augias   # redémarrer
sudo systemctl status augias    # état
journalctl -u augias -f         # suivre les journaux

Emplacement des fichiers​

CheminContenu
/usr/bin/augiasBinaire
/etc/augias/augias.envConfiguration
/var/lib/augias/Données de l'application
/usr/lib/systemd/system/augias.serviceUnité systemd

Mettre à jour​

  • Debian / Ubuntu
  • RHEL / Fedora / CentOS
  • Alpine
sudo apt update && sudo apt upgrade augias
sudo dnf update augias
sudo apk update && sudo apk upgrade augias
